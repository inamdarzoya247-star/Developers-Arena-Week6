# Interactive Sales Dashboard

## Project Overview

This project was developed as part of the Developer Arena Virtual Internship - Week 6.

The project focuses on analyzing sales data and creating statistical and interactive visualizations using Python, Seaborn, Matplotlib, and Plotly.

## Objectives

- Analyze sales data
- Understand product-wise sales performance
- Study sales and quantity distributions
- Analyze relationships between numerical variables
- Create a 2×2 dashboard
- Create an interactive Plotly visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Dataset

The project uses `sales_data.csv`.

The dataset contains 100 rows and 7 columns:

- Date
- Product
- Quantity
- Price
- Customer_ID
- Region
- Total_Sales

## Visualizations

The project includes:

- Product-wise Sales Bar Chart
- Sales Distribution Box Plot
- Quantity Distribution Violin Plot
- Correlation Heatmap
- Daily Sales Trend Line Chart
- 2×2 Sales Dashboard
- Interactive Price vs Total Sales Chart using Plotly
